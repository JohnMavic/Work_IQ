How It Works — The Four Phases

📡 1. Discovery
📋 2. Enrichment
🔍 3. Update Check
🔗 4. Consolidation
📸 Screenshot: Phase 1 — Discovery

📡 Discovery

Agent Zero scans your recent Outlook emails and Teams messages — subjects only, no reading bodies. It identifies action items and creates new tasks, skips duplicates, and updates existing ones.

The AI quickly analyzes conversation subjects to detect actionable items, then intelligently creates tasks without accessing sensitive message content.

📸 Screenshot: Phase 2 — Enrichment

📋 Enrichment

For each new task, the agent reads the full conversation thread. It creates a smart summary with temporal awareness — distinguishing current action from historical context.

The enrichment process understands what happened in the past versus what needs to happen now, creating clear, actionable summaries that give you the context you need.

📸 Screenshot: Phase 3 — Update Check

🔍 Update Check

Later, Agent Zero re-checks each thread for new activity. New replies, decisions, or deadline changes are detected and prepended to the task summary.

You never miss an update. The AI continuously monitors your conversations and surfaces relevant changes, keeping your action items fresh and accurate.

📸 Screenshot: Phase 4 — Consolidation

🔗 Consolidation

Finally, it analyzes all tasks for semantic overlaps. Related or duplicate tasks are grouped, and merge suggestions are presented for your approval.

The AI finds connections between tasks that might be about the same topic, but you're always in control. Review suggestions and decide what to merge or keep separate.
